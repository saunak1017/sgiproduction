# Shivani logo

The portal loads `shivani-logo.svg` here in both the sidebar and the login page.

To use the final Shivani artwork, replace `shivani-logo.svg` with the approved SVG while keeping the same filename. Keep a wide wordmark-style `viewBox`; the UI scales the artwork without stretching it. If the source logo is supplied as PNG instead, add it here and update `brand()` in `public/app.js` to point to that filename.
